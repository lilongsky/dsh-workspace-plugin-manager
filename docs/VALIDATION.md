# 验证说明

版本：`0.1.0-prototype.1`。验证日期：2026-10-19 至 2026-10-20。宿主接口目标：DSH `0.2.1-rc.2`。

## 已验证

| 范围 | 环境 | 结果 |
| --- | --- | --- |
| 核心管理器 | 隔离 SDK；Node 24.21.0 / 26.12.0 | 17/17 通过 |
| 原生配置持久化 | 临时 profile；原生 Loader、Settings、ConfigEditor | 落盘与销毁/重建恢复通过；A/B 提示词分别为 `Native A`、`Native B` |
| 浏览器页面 | 独立无头 Chromium 155.0.8059.84、React 页面、临时原生 profile | 7 项检查通过；无页面运行错误 |

核心用例覆盖并发 A/B 请求、同工作区多个对话、配置更新边界、仅关闭一方、工具视图、并发保存、恢复默认、全局插件拒绝工作区覆盖、跨区两端开关、忙碌/排队会话、来源校验、变更目录后的重新绑定、卸载清理以及适配器部分注册失败后的清理。

浏览器检查包括 A 保存、B 初始独立、A/B 参数独立、关闭 A 保留 B、全局插件无伪开关、页面保存影响隔离 Agent 提示词、无页面运行错误。最终 A 的工作区指令为空，B 保留 `B：另一套项目指令`。页面中的插件清单为测试数据，截图见 [工作区插件页面](images/workspace-manager-ui.png)。

验证使用独立 SDK、临时 profile 和测试 Agent。模型请求、运行中 DSH 连接及正式 profile 写入均为 0。测试代码随仓库提供，重跑方法见 [README](../README.md)。SDK、临时 profile、机器绝对路径和原始环境收据不公开；本文件记录结果及证据边界。
